# 🥑 NutriRec: Умный рекомендатор рационов питания

Интеллектуальная система подбора персонального питания на основе векторного поиска и больших языковых моделей (LLM). Проект разработан в рамках дипломной работы.

## 🌟 О проекте

Приложение рассчитывает индивидуальную суточную норму калорий (по формуле Харриса-Бенедикта) и, опираясь на цели пользователя (похудение, набор массы или поддержание веса), генерирует сбалансированный рацион на день или неделю.

Вместо жёстких фильтров используется **векторная семантика (RAG)**: блюда «умно» подбираются из огромной базы рецептов с учётом БЖУ и исключением известных аллергенов. Встроенная интеграция с **GigaChat (Сбер)** выступает в роли диетолога и генерирует персонализированные объяснения для каждого блюда.

## 🚀 Основные возможности

- **Точный расчёт КБЖУ** — учитываются рост, вес, возраст, уровень активности и фитнес-цели
- **Векторный семантический поиск** — `sentence-transformers` + `ChromaDB` для умного подбора рецептов
- **Интеграция с LLM (GigaChat)** — нейросеть объясняет, почему блюдо подходит под ваши цели
- **Фильтрация аллергенов** — молоко, яйца, глютен, орехи, соя, мёд, красное мясо, паслёновые и др.
- **Аутентификация и профили** — личный кабинет с историей рекомендаций
- **Гибкий UI/UX** — интерактивный интерфейс на Streamlit с цветовой индикацией отклонений от нормы

## 🛠 Технологический стек

| Компонент | Технология |
|---|---|
| Frontend & Backend | [Streamlit](https://streamlit.io/) (Python 3.11+) |
| Vector Database | [ChromaDB](https://www.trychroma.com/) |
| NLP & Embeddings | `sentence-transformers` (`all-MiniLM-L6-v2`) |
| LLM Engine | [GigaChat](https://developers.sber.ru/portal/products/gigachat) (Сбер) |
| Data Processing | Pandas, NumPy |

## 📦 Установка и запуск

### 1. Клонируй репозиторий
```bash
git clone https://github.com/irisich/food-recommender.git
cd food-recommender
```

### 2. Установи зависимости
```bash
pip install -r requirements.txt
```

### 3. Настрой API ключ

Скопируй файл-шаблон и заполни свой ключ:
```bash
cp .env.example .env
```

Открой `.env` и вставь свой авторизационный ключ с [developers.sber.ru](https://developers.sber.ru/):
```
GIGACHAT_API_KEY=твой_ключ_здесь
```

### 4. Запусти приложение
```bash
streamlit run app.py
```

```
├── nutrition.py        # Расчёт КБЖУ

├── data/

├── profiles/           # Профили пользователей (не в git)

```
