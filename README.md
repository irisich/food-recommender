# 🥑 NutriRec: Умный рекомендатор рационов питания

Добро пожаловать в репозиторий проекта **NutriRec** — интеллектуальной системы подбора персонального питания на основе векторного поиска и больших языковых моделей (LLM). Проект разработан в рамках дипломной работы.

## 🌟 О проекте

Приложение рассчитывает индивидуальную суточную норму калорий (по формуле Харриса-Бенедикта) и, опираясь на цели пользователя (похудение, набор массы или поддержание веса), генерирует сбалансированный рацион на день или неделю. 

Вместо жестких фильтров используется **векторная семантика (RAG)**: блюда "умно" подбираются из огромной базы рецептов с учетом БЖУ, исключая известные аллергены. А встроенная интеграция с **OpenAI GPT-3.5-turbo** выступает в роли диетолога, генерируя персонализированные объяснения для каждого блюда.

## 🚀 Основные возможности

- **Точный расчет КБЖУ**: Учитываются рост, вес, возраст, уровень активности и фитнес-цели.
- **Векторный семантический поиск**: Используется модель `sentence-transformers` и база `ChromaDB` для интеллектуального поиска рецептов по смыслу.
- **Интеграция с LLM (OpenAI API)**: Нейросеть объясняет, почему конкретное блюдо подходит под ваши макронутриенты и аллергии.
- **Фильтрация аллергенов**: Поддержка исключения молока, яиц, глютена, орехов, сои, меда, красного мяса, пасленовых и др.
- **Гибкий UI/UX**: Интерактивный интерфейс на основе Streamlit с цветовой индикацией отклонений от нормы калорийности.

## 🛠 Технологический стек

* **Frontend & Backend**: [Streamlit](https://streamlit.io/) (Python 3.11+)
* **Vector Database**: [ChromaDB](https://www.trychroma.com/) (Ephemeral in-memory)
* **NLP & Embeddings**: `sentence-transformers` (`all-MiniLM-L6-v2`)
* **LLM Engine**: `openai` (GPT-3.5-turbo)
* **Data Processing**: Pandas, Numpy

## 📦 Запуск проекта

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/ВАШ_ЛОГИН/food-recommender.git
   cd food-recommender
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Добавьте ваш OpenAI ключ в `config.py` (строка 18):
   ```python
   OPENAI_API_KEY = "sk-..."
   ```

4. Запустите приложение:
   ```bash
   streamlit run app.py
   ```
